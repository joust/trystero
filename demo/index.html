Trystero feature demo

All four feature branches combined. Open this page in 2–3 tabs (same URL) to get peers connecting to each other.
self: room: demo active peers: 0

1. onError (#90)

Every error surfaces here. Press the button to simulate a send to a non-existent peer — you should see an action error.

2. stream-rejection (#125)

Open two tabs. On the sender tab, press "send big blob" — the receiver aborts at ~30% by returning false from its progress handler. Watch both bars and the log.

sender: 0%
receiver: 0%

3. maxPeers (#141)

This page joins with maxPeers: 2. Open a 3rd tab — the 3rd joiner should be rejected (log line, no onPeerJoin fires).

4. iceReconnect

Enabled via iceReconnect: true. With two tabs connected, disable your Wi-Fi or use DevTools → Network → Offline for a few seconds, then restore. You should see a reconnect log line rather than a permanent peer-leave.

5. App-level resumable transfer (bonus)

Not part of trystero itself — a thin helper on top. Splits a file into 64 KB logical chunks, exchanges a manifest, then sends only the chunks the receiver doesn't have yet. Abort mid-send, then click resume — only the gap chunks are re-sent.
